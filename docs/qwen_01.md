Исключения-кирпичики, где строка переносима: список русских месяцев (LJ 444) и регексты дат/вложенности (LJ 455, 653–663; VK V236, V291) — они про формат, не про верстку.

### Кирпичики для Анкеты-ОК (атом → тезис → источник в файле → вердикт)

**B1. Форма анкеты и регистрация.** VK V1–V2 и V294: `shortname/urls/title/procedure/functions` → `AllSocProcs.set`. LJ 12–15: старое поколение, ручная регистрация `KnownSNets.set` с функциями. **Брать форму VK** (snettemplate ест AllSocProcs); регистрацию LJ не брать. Для ОК: `urls ["ok.ru","m.ok.ru"]` — мобильная ось по образцу VK V1.

**B2. Типы страниц по url.** LJ 26–58 `detectPageType`: четыре типа регекстами + имя из поддомена + нормализация `_`→`-` (LJ 52). **Брать идею таксономии**, подставить источник: типы ОК = profile (`/profile/NNN` или слаг `имя.число{6,}`), group (`/group/NNN`, `groupNNN` без слэша, короткий слаг), discussions (`/discussions/…/<topic>/<message>`), нить ЛС; идентификатор из пути, не из хоста.

**B3. Точки входа зон (queryaz).** VK V3, V43, V52, V59: зона начинается селектором входа. **Брать механизм**; для ОК входы: `a[href^="/profile/"]`, ссылка автора внутри контейнера комментария, заголовок темы дискуссии, заголовок группы. **Анти-кирпич:** хэшированные классы VK V52, V59 (`vkit…--RpTRm`) — урок реконструкции: для ОК никаких хэшей, только href-шаблон и структурные маркеры.

**B4. Цепочка идентичности.** VK V69–V100: сначала data-атрибуты (`mention_id`, `data-from-id`), потом href (`usernamebyhref VERIFIED`). LJ 1–3: имя из адреса, не из атрибута формы. **Брать цепочку с обратным приоритетом** (у ОК data-атрибутов нет): href первым, отображаемый текст вторым; нормализация персона/сообщество по префиксу пути.

**B5. eventype по контейнеру.** VK V5–V12: подъём вверх по классам (`pv_photo_wrap`→0, `reply_content`→1, иначе 2). LJ 149–150 (пост=2), 183–184 и 202–203 (коммент=1), 312–313 (упоминание=0), 330–333 (свой пост=5, чужая ссылка=4). **Брать оба**: контейнер комментария ОК (блок со словом «Ответить»)→1, блок темы/поста→2, голое имя→0, подсветка своего поста→5.

**B6. Куда вешать вход в дверцу и счётчик.** VK V47–V49: `attachBadgeMode after`, меню подъёмом до `PostHeaderTitle`, бейдж подъём до `PostHeader` и спуск к аватару. LJ 78–79, 311, 388–390: меню на ссылку-картинку (`i-ljuser-profile`, `post-card__userpic`). **Брать LJ-семантику «меню на аватар» + VK-операции up/down**; для ОК: меню на ссылку-аватар в шапке коммента/поста, бейдж на контейнер имени, режим after.

**B7. captElement (заголовок события).** LJ 80–82, 109–111, 120–122, 133–135, 143–145, 391: заголовок по диалекту. **Брать идею**: для ОК captElement = заголовок темы в дискуссиях, шапка поста в группе, имя-шапка в профиле; строки — из проверок F12.

**B8. url события / пермалинк.** LJ 151–156 (url без query), 187–196, 204–206, 241–245, 261–264 (пермалинк = дочерняя ссылка с `#` или `comment-permalink`). VK V16–V40 (дата-ссылка `wd_lnk`, иначе url+`#`+id), V216–V222 (`data-post-id` → синтез wall-url). **Брать согласие обоих**: пермалинк комментария ОК = href даты-ссылки (глубокая ссылка `/discussions/…/<message>` — факт прогонов); url поста = текущий url без query; синтез не нужен.

**B9. totalblock (скрыть событие целиком).** LJ 185, 208–211, 234–236, 248–251, 254–259, 278 (id-регекс `^ljcmt*`); VK V41, V65 (подъём до `reply_dived` / `vkitCommentBase__root`). **Брать**: totalblock ОК = контейнер комментария; если у блоков ОК есть стабильный префикс id — проверить F12 и взять id-регекс, иначе подъём по маркеру.

**B10. Предохранитель зоны.** LJ 266–268: свёрнутый комментарий (нет текста) → `isModifiable=false`. **Брать как есть**: зона ОК без текста не помечается.

**B11. Конвейер даты.** LJ 438–~560: элемент по диалекту → текст → мультипарсер (ISO, русские и английские месяцы, 12ч am/pm, время опционально) с флагом success; список `rusmonthsshort` LJ 444. VK V101–V200: приоритет машинного атрибута `time` (epoch) → текстовый формат → относительная дата с success=false. **Брать конвейер и список месяцев дословно**, добавить ветку относительных дат («вчера», «2 часа назад») с success=false.

**B12. Текст и заголовок события.** LJ ~565–~640 `GetLjEventText` (заголовок+текст по диалекту с фолбэками); VK V237–V290 `gettext` (текст комментария, текст поста, пост-без-текста → src картинки как текст, мобильная ветка по `data-testid`). **Брать схему с фолбэком**: текст комментария ОК = innerText контейнера минус автор/дата/управление; фотопост → подпись/alt вместо src.

**B13. Политика алиаса.** LJ ~644–~652: обрезать «(…)» из отображаемого имени. VK V223–V235: дописывать « (id)». **Брать политику LJ** для ОК (имена вида «Елена Пересичан( Лычная)»); id держать в удостоверениях карточки, не в алиасе; решение зафиксировать комментарием в анкете.

**B14. Корень и вложенность.** LJ ~653–~663: корень = url без query; вложенность = candidate включает root. VK V236 (`match ^([^?]*)`) и V291 (`accept/get/test`). **Брать дословно**: обе реализации согласны; для ОК корень = discussions-url до `<topic>`, вложенность = тот же топик с другим `<message>` или `#`-якорем.

**B15. Оси диалектов.** LJ ~664–~700 `GetLayoutType`: диалект верстки по отпечатку-маркеру (селектор с длиной 1). VK: ось `ismobile` во всех ветках. **Брать обе оси**: для ОК ось1 = тип страницы (B2), ось2 = ok.ru против m.ok.ru; отпечаток-маркер как предохранитель перед обходом зон.

**B16. Язык анкеты.** LJ-хелперы (~701–конец: `getParentElementBelobgsToClass`, `getIndirectChildElementBelongsToClass`, `getUpDownByClassElement`) = семантический словарь; VK-операции (up, down, attr, test, classcontains, set, get, init, return, if, iseq, func, concat, match, replace, queryselector, url, epochtime, vktime, curdate, ismobile, in, firstchild, nodevalue, accept) = язык исполнения. **Брать правило**: анкета ОК пишется только на языке VK-операций (правило №0); каждый LJ-хелпер переводится в цепочку этих операций, ручного JS в анкете нет.

### Как сложить кирпичики (порядок в okcom.js)

B1 оболочка → B2 типы → на каждый тип свои B3 входы → на каждый вход цепочка B4→B5→B6→B7→B8→B9→B10 → функции B11, B12, B13, B14 → всё с учётом осей B15 и только на языке B16. Ворота: каждая строка селектора в анкете имеет напротив себя строку из списка точечных проверок F12; без такой строки селектор в анкету не попадает.
