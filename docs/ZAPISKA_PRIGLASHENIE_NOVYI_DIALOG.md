## 0. Фундамент: контракт адаптера dmiandr/context (вычитан из кода дословно)

- Адаптер — не программа, а анкета. Каждый именной файл портала
  (vkcom.js, ljcom.js, habrcom.js…) кладёт в AllSocProcs декларацию:
  shortname, title, urls (подстроки адреса портала), functions (селекторы/парсеры зон).
- snettemplate.js собирает объект из анкеты: Mark = совпал ли location.href с urls;
  методы ListActiveZones, GetTimestamp, GetEventText, GetUserAlias, GetRootFor,
  IsNested — все из шаблонов. Движок один, порталов семь, код портала — только анкета.
- Метки живут прямо в DOM, никакого стекла: setBadge вставляет span.repubadge
  потомком или соседним элементом (attachBadgeMode: child/after), событие помечается
  классом history на captElement, статус красит userelem через стиль (colorAll).
  Меню — insertBefore рядом с attachMenuDomElement.
- Зона описана структурой (initazone): element, captElement, username,
  attachMenuDomElement, attachBadge, userelem, eventype… движку хватает анкеты,
  чтобы знать, куда цеплять.

- Внедрение ОК находится в стадии **подготовки**: собран только регламент сбора и инструменты ручного исследования.

- Подтверждены только URL-образцы трёх типов страниц: `/profile/`, `/group/`, `/discussions/…/<message>`.

## 4. Урожай по ОК (проверено прогонами и свидетельствами руководителя)

- url: профиль = /profile/NNN или слаг имя.число{6,}; группа = /group/NNN,
  groupNNN без слэша или короткий слаг; дискуссии = /discussions/…/<topic>/<message>.
- Пермалинк комментария = клик по дате комментария; ссылка сообщения ЛС = иконка-цепочка.
- Shadow DOM на ОК нет; DOM стабилен; стекло/оверлей не применяются.
- headed Edge + CDP жив; headless антибот ОК блочит — headless только на нейтральном вебе.
