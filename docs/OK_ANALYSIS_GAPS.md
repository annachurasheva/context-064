## 4. Факты, которые НЕЛЬЗЯ использовать (риски)

В файле `ok_ru_mbuktskska.txt` **нет** строк селекторов, классов или DOM-структур, поэтому риск слепого копирования отсутствует — но важно не подставлять **гипотезы из головы**:

- Хэшированные классы (по образцу VK `vkit…`) — для ОК не подтверждены; не выдумывать.
- Форматы дат — не собраны; нельзя предполагать.
- Поведение страницы (SPA/не-SPA) — не определено; нельзя утверждать.
