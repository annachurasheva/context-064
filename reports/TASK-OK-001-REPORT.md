## Изученные документы

### 1. `docs/qwen_01.md` — Контракт адаптера OK.RU
**Ключевые положения:**
- Область применения: только десктопная версия ok.ru (Microsoft Edge).
- Мобильные представления (m.ok.ru, мобильные UI) игнорируются.
- Все действия строго через DevTools (F12).

**Правила:**
- **Правило №0:** Нет факта из DOM → стоп и вопрос Дельте. Запрещено выдумывать селекторы, атомы, зоны.
- **Правило №1:** Атомарность — каждое взаимодействие разбито на минимальные неделимые элементы (атомы A1..An).
- **Правило №2:** Связывание — атомы объединяются в логические блоки (кирпичики B1..Bn).
- **Правило №3:** Протоколирование — каждый атом и кирпичик должен быть протоколирован.

**Атомы (A1-A14):** Открытие страницы, авторизация, поиск элемента, чтение текста/атрибута, клик, ввод текста, прокрутка, загрузка изображения, сохранение данных, проверка состояния, ожидание загрузки, закрытие/переключение вкладки.

**Кирпичики (B1-B16):** Загрузка профиля, навигация, просмотр новостей, комментирование, лайк, репост, загрузка фото, отправка сообщения, поиск пользователей, добавление/удаление из друзей, блокировка, просмотр/редактирование профиля, настройки приватности, выход из аккаунта.

### 2. `docs/REGULATION_OK_COLLECTION_V01.md` — Регламент сбора информации
**Методы сбора:**
1. Console API для выполнения JavaScript команд.
2. Elements панель для анализа DOM.
3. Network панель для анализа запросов.
4. Sources панель для отладки.

**Требования к сбору:**
- Все данные должны быть собраны из реального DOM.
- Все селекторы должны быть проверены на актуальность.
- Все найденные элементы должны быть задокументированы.
- Все изменения на странице должны быть зафиксированы.

**Формат отчёта:**
- Полные тексты файлов через Code Tool Record → Diff → Copy.
- Один ток — один шаг — один отчёт.
- Все отчёты нумеруются последовательно.
- Все отчёты подписываются датой и временем.

**Безопасность:**
- Не использовать автоматизацию, которая может быть расценена как бот.
- Не отправлять запросы чаще чем 1 в 2 секунды.
- Не изменять состояние страницы без явного разрешения.
- Не собирать персональные данные без необходимости.

### 3. `docs/INSTRUCTION_OK_ATOMS_A1_A6.md` — Протокол F12 для атомов A1-A6
**Инструкции по применению:**

| Атом | Описание | Пример кода в Console |
|------|----------|----------------------|
| A1 | Открытие страницы ok.ru | `window.location.href === 'https://ok.ru/'` |
| A2 | Авторизация пользователя | `document.querySelector('#field_email') && document.querySelector('#field_password')` |
| A3 | Поиск элемента по селектору | `const element = document.querySelector('селектор'); element ? element.outerHTML : null;` |
| A4 | Чтение текста элемента | `const element = document.querySelector('селектор'); element ? element.textContent.trim() : '';` |
| A5 | Чтение атрибута элемента | `const element = document.querySelector('селектор'); element ? element.getAttribute('атрибут') : null;` |
| A6 | Клик по элементу | `const element = document.querySelector('селектор'); if(element) { element.click(); true; } else { false; }` |
